Bare lige en husker:
    Amdahls: Hvor meget hurtigere kan vi klare samme opgave.
        SpeedUp(P, N) = 1 / ((1 - P) + (P / N))

        P = parallelizable fraction (e.g. 0.90 for 90%)
        N = number of GPUs
        Max speedup as N -> infinity: 1 / (1 - P)

    Gustaffsons: Hvor meget større en opgave kan vi klare på samme tid.
        S(N) = N - a * (N - 1)

        a = sequential fraction (e.g. 0.05 for 5%)
        N = number of GPUs
